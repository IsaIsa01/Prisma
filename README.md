# Prisma — как выложить в интернет и поставить на телефон

В папке всё, что нужно. Ничего собирать и компилировать не надо, никакого npm.

```
index.html              приложение целиком
config.js               адрес и ключ базы — единственный файл, который надо править
manifest.webmanifest    описание для установки на телефон
sw.js                   офлайн-кэш
icon-192.png            иконки
icon-512.png
apple-touch-icon.png
favicon.png
supabase.sql            запрос для создания таблицы
```

---

## Шаг 1. Проверить локально (2 минуты)

Открой `index.html` двойным кликом. Всё работает, кроме таблицы лидеров — она пока показывает только тебя, и установка на телефон недоступна: для этого нужен настоящий адрес с https.

Если хочешь проверить и service worker тоже — в терминале:

```bash
cd путь/к/папке
python3 -m http.server 8000
```

и открой `http://localhost:8000`.

---

## Шаг 2. База для общей таблицы лидеров (10 минут)

Без этого шага приложение работает, но прогресс живёт только в браузере на одном устройстве.

1. Зайди на **supabase.com**, зарегистрируйся, нажми **New project**. Регион выбери поближе — Frankfurt. Пароль базы можно не запоминать, он тут не понадобится.
2. Дождись, пока проект поднимется (пара минут).
3. Слева **SQL Editor** → **New query**. Вставь целиком содержимое `supabase.sql`, нажми **Run**. Должно написать Success.
4. Слева **Project Settings → API**. Скопируй два значения:
   - **Project URL** — вида `https://abcdefgh.supabase.co`
   - **anon public** ключ — длинная строка, начинается с `eyJ`
5. Открой `config.js` — это девять строк — и впиши свои значения:

```js
window.PRISMA_CONFIG = {
  url: 'https://abcdefgh.supabase.co',
  key: 'eyJhbGciOi...'
};
```

Сохрани. Больше ничего править не нужно, `index.html` трогать не надо.

### Если правишь прямо в браузере

Весь шаг делается онлайн, без единого приложения на компьютере:

1. **github.com** → регистрация → **New repository** → имя `prisma`, Public → Create.
2. На пустой странице репозитория ссылка **uploading an existing file**. Перетащи туда все файлы из папки → **Commit changes**.
3. Открой `config.js` → карандаш справа сверху → впиши url и key → **Commit changes**.
4. Дальше подключи репозиторий к Netlify (Add new site → Import an existing project) или включи GitHub Pages: **Settings → Pages → Branch: main / root → Save**.

После этого любое обновление — правка в браузере плюс Commit, сайт пересобирается сам. Это же лечит и главную проблему drag-and-drop: не нужно каждый раз перетаскивать папку заново.

Годятся и онлайн-редакторы вроде StackBlitz или CodeSandbox — импортируешь папку, правишь, скачиваешь обратно.

**Про безопасность.** `anon` ключ публичный, его видно любому, кто откроет страницу — так и задумано. Защита стоит на уровне политик базы, которые ты только что создал: они разрешают читать и писать таблицу с результатами и больше ничего. Имя игрока паролем не защищено: кто угодно, кто откроет ссылку, может ввести чужое имя. Для игры с друзьями это нормально; просто не считай таблицу защищённой и не храни в этом проекте ничего важного.

## Шаг 3. Выложить в интернет (5 минут)

**Самый быстрый способ — Netlify Drop.** Бесплатно, https сразу, ничего настраивать не надо.

1. Открой **app.netlify.com/drop**
2. Перетащи туда **всю папку** целиком (не отдельные файлы).
3. Через полминуты получишь адрес вида `https://sparkly-narwhal-a1b2c3.netlify.app`.
4. Зарегистрируйся, чтобы сайт закрепился за тобой, иначе он временный.
5. В **Site configuration → Change site name** поменяй адрес на что-то человеческое, например `prisma-math.netlify.app`.

Кидай ссылку друзьям. Каждый вводит своё имя — и появляется в таблице.

**Обновление позже:** заходишь в **Deploys** и перетаскиваешь обновлённую папку туда же. Только перед этим поменяй в `sw.js` строку `const CACHE = 'prisma-v1'` на `v2`, `v3` и так далее — иначе телефоны будут показывать старую версию из кэша.

*Альтернатива, если хочешь версионирование:* залей папку в репозиторий на GitHub и подключи его в Netlify или Vercel — тогда обновление это `git push`.

## Шаг 4. Поставить на телефон

Это PWA — ставится как обычное приложение, без App Store и без Google Play.

**iPhone.** Открой сайт **обязательно в Safari** (в Chrome на айфоне пункта не будет). Кнопка «Поделиться» внизу → пролистай вниз → **На экран «Домой»** → Добавить. Появится иконка с пузырём, запускается на весь экран без адресной строки.

**Android.** Открой в Chrome. Меню из трёх точек → **Установить приложение** (или «Добавить на главный экран»).

**Ноутбук.** В Chrome в адресной строке справа появится значок установки.

---

## Шаг 5. Свой домен (по желанию)

Домен стоит порядка 10–15 € в год. Купить можно на Namecheap или Cloudflare, дальше в Netlify **Domain management → Add a domain**, и Netlify сам покажет, какие DNS-записи прописать. Сертификат https он выпустит автоматически.

## Если что-то не работает

**Начни отсюда.** Открой вкладку **Board** и нажми **Check the database connection**. Приложение само проверит config.js, попробует прочитать таблицу, попробует записать строку и напишет диагноз с конкретным HTTP-кодом и текстом ошибки от Supabase.

Что означают ответы:

| Что показала проверка | Причина | Лечение |
|---|---|---|
| `config.js loaded : NO` | Файл не залился на хостинг или лежит не рядом с index.html | Проверь, что `config.js` виден по адресу `твой-сайт/config.js` |
| `key type : unrecognised` или `missing` | Ключ не вставлен или вставлен с обрезанным началом | Скопируй ключ заново целиком |
| `key type : SECRET` | Взят `service_role` / `secret` ключ | Нужен `anon` или `sb_publishable_`; секретный в браузер нельзя |
| read test **401** / **403** | Либо ключ не тот, либо не созданы политики RLS | Выполни `supabase.sql` в SQL Editor и убедись, что написало Success |
| read test **404** | `supabase.sql` выполнен в другом проекте, либо схема public не отдана в Data API | Проверь, что в Table Editor видна таблица `players` |
| read test 200, write test **401/403** | Читать можно, записывать нет — значит политики insert/update не создались | Прогони `supabase.sql` ещё раз целиком |
| read test 200, rows 0 | Всё работает, таблица пустая | Реши одну задачу и обнови вкладку |
| `network failure` | Опечатка в url, либо проект в Supabase уснул | На бесплатном тарифе проект засыпает после недели простоя — разбуди его в дашборде |

**Проверка руками, если хочется убедиться отдельно.** Вставь в адресную строку браузера, подставив свои значения:

```
https://ТВОЙ-REF.supabase.co/rest/v1/players?select=*&apikey=ТВОЙ-КЛЮЧ
```

Если вернулся `[]` или список игроков — база и ключ в порядке, дело в файлах на сайте. Если вернулась ошибка — дело в Supabase.

**Формулы выглядят как обычный текст** — не загрузился KaTeX с CDN. Приложение специально не падает, а показывает формулы простым текстом. Проверь интернет.

**Друг ввёл имя, но не появился в таблице** — скорее всего у него открыта закэшированная старая версия. Пусть удалит иконку с экрана и откроет ссылку заново.

**Телефон показывает старую версию** — не поменял номер в `CACHE` в `sw.js`. Быстрое лечение на самом телефоне: удалить иконку с экрана и поставить заново.
